# ranebhushan.github.io

Source for my personal website: **https://ranebhushan.github.io/**

## Structure

```
index.html   single page entry point
css/         default.css, layout.css, media-queries.css, magnific-popup.css,
             plus vendored fonts/icon fonts (fonts.css, font-awesome, fontello)
images/      site images
js/          modernizr.js (only script currently loaded)
```

## Deployment

Hosted on GitHub Pages, served directly from the `master` branch.
